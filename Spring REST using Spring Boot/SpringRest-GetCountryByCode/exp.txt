package com.cognizant.spring_learn.service;

import com.cognizant.spring_learn.model.Country;
import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class CountryService {

    public Country getCountry(String code) {

        ApplicationContext context =
                new ClassPathXmlApplicationContext("country.xml");

        List<Country> countries =
                context.getBean("countryList", List.class);

        for (Country country : countries) {

            if (country.getCode().equalsIgnoreCase(code)) {

                return country;

            }

        }

        return null;
    }

}

Why @Autowired?
@Autowired

CountryService service;

Instead of

CountryService service = new CountryService();

Spring creates the CountryService object for you and injects it into the controller. This is called Dependency Injection (DI).

Why @Service?
@Service

It tells Spring:

"Create an object of this class and manage it as a Spring bean."

That allows @Autowired to inject it into the controller.

Why @RestController?

@RestController combines two annotations:

@Controller
@ResponseBody

@ResponseBody tells Spring to write the returned Country object directly into the HTTP response. Spring uses Jackson to convert it into JSON automatically.

Interview Explanation (1 minute)

When the client sends a GET request to /countries/{code}, the request is received by the DispatcherServlet, which maps it to CountryController. The @PathVariable extracts the country code from the URL. The controller delegates the request to CountryService. The service loads country.xml, retrieves the countryList bean from the Spring IoC container, iterates through the list using equalsIgnoreCase() to perform a case-insensitive search, and returns the matching Country object. The controller returns this object, and Spring Boot uses Jackson to serialize it into a JSON response that is sent back to the client.

Possible Cause 2: Wrong Package

Check the package declaration at the top of CountryService.java.

It must be:

package com.cognizant.spring_learn.service;

If it is something like:

package com.cognizant.springlearn.service;

or

package com.cognizant.service;

Spring won't find it.

Your project should look like this:

what is the autowired ans service

These are two of the most important annotations in Spring. Let's understand them with a simple example.

What is @Service?

@Service tells Spring:

"This class contains business logic. Please create and manage one object (bean) of this class."

Example:

package com.cognizant.spring_learn.service;

import org.springframework.stereotype.Service;

@Service
public class CountryService {

    public String getCountry() {
        return "India";
    }
}

When Spring Boot starts, it sees @Service.

Internally, Spring does something like:

CountryService service = new CountryService();

and stores this object in the Spring IoC Container.

Spring IoC Container
--------------------------
CountryService Object
--------------------------

Without @Service, Spring does not create this object.

What is @Autowired?

@Autowired tells Spring:

"I need an object of this class. If you've already created one, inject it here."

Example:

@RestController
public class CountryController {

    @Autowired
    private CountryService countryService;

}

Spring sees @Autowired.

It checks its IoC container:

IoC Container

CountryService Object

It finds the object and assigns it automatically:

countryService = existingCountryServiceObject;

Now you can call:

countryService.getCountry(code);

without creating the object yourself.

Without @Autowired

You would have to write:

CountryService countryService = new CountryService();

This is called manual object creation.

With @Autowired

You simply write:

@Autowired
CountryService countryService;

Spring creates the object and injects it for you. This is called Dependency Injection (DI).

Real-Life Analogy

Imagine a company.

@Service → An employee is hired and added to the company.
IoC Container → The company's employee database.
@Autowired → Another department asks, "I need the CountryService employee." The company assigns the existing employee instead of hiring a new one.
Why use them?

Without Spring:

CountryService service = new CountryService();

With Spring:

@Autowired
CountryService service;

Benefits:

You don't create objects manually.
Objects are reused.
Classes are loosely coupled.
Easier to test and maintain.
Interview Answer
What is @Service?

@Service is a Spring stereotype annotation that marks a class as the service layer. It tells Spring to create and manage an instance of that class as a bean in the IoC container.

What is @Autowired?

@Autowired is used for dependency injection. It tells Spring to automatically inject a required bean from the IoC container instead of creating the object manually with new.
